# CaraCore-PDV v3.2.4-free — download da loja

**Isto é o que a loja entrega hoje.** Não use a pré-release `v4.0.0-rc2` como se fosse o Free.

Não misture pasta nem data. Canais independentes.

Loja: https://pdv.caracore.com.br/download.html

## Aceite do primeiro acesso

- [ ] O boot imprime `3.2.4-free`
- [ ] Health responde em `http://localhost:8080/q/health`
- [ ] `http://localhost:8080/login` retorna 200
- [ ] Launcher: `iniciar-pdv.bat` (hífen). Banco: `%APPDATA%\caracore\`
- [ ] Sem janela JavaFX — o operador abre o navegador
- [ ] Cadastre um produto e registre a primeira venda no caixa pela interface do navegador (pagamento em dinheiro)

## Requisitos

Java 25+. `java -version` deve mostrar 25. Java 21 no PATH faz o launcher parar.

## O que o Free não inclui

Sem PIX integrado (sem QR/gateway). Pagamentos no Free: dinheiro, débito, crédito e outros — “outros” não é o PIX integrado da loja. Sem emissão fiscal (NF-e/NFC-e).
