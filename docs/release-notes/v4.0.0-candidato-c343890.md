- **Licença Pro por chave assinada (Ed25519).** O token é verificado offline
  contra a chave pública embutida e amarrado ao hardware da máquina; a
  ativação é feita na tela, sem troca manual de arquivo de licença. A consulta
  online de licença é opcional e vem desligada.
- **Atualização pelo gateway único `api.caracore.com.br`.** O cliente lê
  `releases/latest.json`, exige `sha256` e entende o campo `mandatory`
  (aceito como `true`, `"Sim"`, `1`); atualização com confirmação e adiada
  enquanto há venda aberta. Hoje o gateway anuncia a `3.2.12-free`: uma
  instalação 4.0.0 só recebe oferta quando o canal apontar para a v4.
- **Sincronização de vendas na rede local para o CaraCore HUB.** Venda
  finalizada vai ao HUB com token de pareamento. Vem desligada por padrão
  (`caracore.lan.sync.habilitada=false`). É sincronização de vendas — não
  leva estoque nem pedido, e PUDO é recurso do HUB, não do PDV.
