**Isto é o que a loja entrega hoje.** Não use a pré-release `v4.0.0-rc2` (topo da lista de pré-releases) como se fosse o Free.

Não misture pasta nem data. Canais independentes.

Loja: https://pdv.caracore.com.br/download.html

## Aceite do primeiro acesso

- [ ] O boot imprime `3.2.3-free`
- [ ] Health responde em `http://localhost:8080/q/health`
- [ ] `http://localhost:8080/login` retorna 200
- [ ] Launcher: `iniciar-pdv.bat` (hífen). Banco: `%APPDATA%\caracore\`
- [ ] Sem janela JavaFX — o operador abre o navegador

Java 25+. Depois do Temurin 25, feche e abra o terminal. `java -version` deve mostrar 25. Java 21 no PATH faz o launcher parar.
