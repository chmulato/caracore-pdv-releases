# CaraCore PDV 4.0.0-rc3

> **Substituída pela RC4.** Esta nota é apenas histórica; para avaliação, use
> a [v4.0.0-rc4](../wiki-release-v4-0-0-rc4.html).

Pré-release pública histórica **da edição Free**, para avaliação — até **100
vendas finalizadas por mês civil**. Foi substituída pela RC4; a versão Free
estável e multiplataforma continua sendo `v3.2.6-free`.

## Novidades

- Encerramento local autenticado e resposta de desligamento aprimorada.
- Projeções financeiras gerenciais, custo de aquisição opcional e ajustes no simulador fiscal.
- Instrumentação opcional de desempenho, desativada por padrão.
- Limite Free de até 100 vendas finalizadas por mês civil; sem PIX integrado
  nem emissão de NF-e/NFC-e.
- Distribuição limitada ao ZIP portátil Windows x64 sem Authenticode; MSI não incluído.

O hash ajuda a detectar alterações, mas não autentica a identidade de quem
publicou o arquivo. O Windows pode alertar sobre editor desconhecido ou
reputação. Não desative SmartScreen, Defender nem antivírus; interrompa se o
hash local divergir.

## Instalação isolada

Requisitos: Windows x64, Java 25+, Python 3 e Microsoft Edge. Extraia em uma
pasta nova e execute `iniciar_pdv.bat` (underscore). No primeiro acesso,
`admin/admin` exige a troca de senha.

O banco é criado em `./data/caracore-pdv.db`; esta instalação não abre nem altera
`%APPDATA%\caracore\data\banco.db`. Não copie dados de outra instalação.
