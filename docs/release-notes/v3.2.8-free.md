# CaraCore PDV Free 3.2.8

**Publicação:** 14/10/2026  
**Canal:** estável · Windows, Linux e macOS · Java 25+  
**Release:** [v3.2.8-free](https://github.com/chmulato/caracore-pdv-releases/releases/tag/v3.2.8-free)

## Destaques

- Novo caixa de balcão com inclusão assíncrona, foco preservado e atalhos.
- Leituras repetidas consolidam quantidades; entrada `quantidade*código` funciona com leitor e digitação.
- Estoque é baixado e estornado agregando linhas repetidas do mesmo produto.
- Quantidade, desconto com motivo auditado e CPF opcional validado e mascarado na venda.
- Pagamento em modal com cálculo de falta/troco.
- Recibos HTML/PDF mostram subtotal e desconto; o CPF permanece mascarado.
- Launcher seleciona Java 25+ via `PDV_JAVA`, `JAVA_HOME` ou `PATH`.

## Limites e validação

- O plano Free mantém até 100 vendas finalizadas por mês civil, sem PIX integrado nem emissão de NF-e/NFC-e.
- O segundo turno no mesmo dia permanece adiado até que haja identificação persistente de turnos.
- Os testes automatizados focados passaram; a homologação manual completa no Edge, incluindo o roteiro com leitor físico, não foi concluída para esta publicação.
- Faça backup dos dados antes de atualizar uma instalação existente.
