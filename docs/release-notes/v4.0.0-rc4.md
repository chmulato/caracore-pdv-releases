# CaraCore PDV 4.0.0-rc4

Pré-release pública **da edição Free**, para avaliação — até **100 vendas
finalizadas por mês civil**. Não é GA nem está homologada para operação de
produção; a versão Free estável e multiplataforma continua sendo
`v3.2.6-free`.

## Correções

- Versão RC4 unificada no boot, heartbeat, manifesto e telas de entrada.
- Heartbeat e logs direcionados para `./data`; o banco permanece em
  `./data/caracore-pdv.db`, sem gravar nos diretórios legados do usuário.
- Superfícies Premium/fiscais do Free ocultadas ou bloqueadas com resposta
  amigável; correções nas telas de pagamento e fiscal.
- Caixa considera o valor líquido após o troco; rótulos de pagamento e
  estimativa de impostos ajustados.
- Atalhos de balcão, total da venda, vendedor padrão e estado vazio/seed
  opcional ajustados.
- Endpoints de documentação fechados em produção, shutdown validado por
  método/token e recibo com estilos locais para uso offline.
- Bootstrap do primeiro acesso corrigido para alinhar as colunas legadas da
  senha com o hash atual.

O plano Free **não** inclui PIX integrado nem emissão de NF-e/NFC-e. O limite
de 100 vendas finalizadas por mês civil continua ativo.

hash local divergir.

## Instalação isolada

Requisitos: Windows x64, Java 25+, Python 3 e Microsoft Edge. Extraia em uma
pasta nova e execute `iniciar_pdv.bat` (underscore). No primeiro acesso,
`admin/admin` exige a troca de senha. Edge/Windows em 1280×800 e o fluxo de
primeiro acesso foram validados em testes internos; o roteiro operacional
formal continua pendente antes do GA.

O banco é criado em `./data/caracore-pdv.db`; esta instalação não abre nem altera
`%APPDATA%\caracore\data\banco.db`. Não copie dados de outra instalação.
