Status da pré-release

A RC4 corrige achados de QA da RC3. Edge/Windows em 1280×800 e o fluxo de primeiro acesso foram validados em testes internos; o roteiro operacional formal permanece pendente antes do GA.

Esta pré-release usa o plano Free, com limite de 100 vendas finalizadas por mês civil. A versão 3.2.7-free continua sendo a versão estável e multiplataforma. Não misture instalações, launchers nem bancos.

Correções desta pré-release

  • Versão RC4 unificada no boot, heartbeat, manifesto e telas de entrada.
  • Heartbeat, logs e banco isolados sob ./data; sem escrita nos diretórios legados do usuário.
  • Superfícies Premium/fiscais do Free ocultadas ou bloqueadas com resposta amigável; correções nas telas de pagamento e fiscal.
  • Caixa considera o valor líquido após o troco; atalhos e apresentação do caixa ajustados.
  • Documentação da API fechada em produção, shutdown protegido e recibo com CSS local para uso offline.
  • Correção do bootstrap administrativo no primeiro acesso.

O Free não inclui PIX integrado nem emissão de NF-e/NFC-e.

Download e verificação

Antes de extrair, compare o SHA-256 abaixo com o resultado local. O hash ajuda a detectar alteração do arquivo, mas não autentica a identidade do publicador.

Arquivo: CaraCore-PDV-4.0.0-rc4-qute-portable-windows-x64.zip
SHA-256: 31a0cdeda68dce058079c5d0d3d5652084ba8a8cc073dfce60e021c4b3c1fdf2

No PowerShell: Get-FileHash .\CaraCore-PDV-4.0.0-rc4-qute-portable-windows-x64.zip -Algorithm SHA256

Este ZIP não tem assinatura Authenticode. O Windows pode exibir alertas de editor desconhecido ou reputação. Não desative SmartScreen, Defender ou antivírus; interrompa se o hash divergir.

Instalação isolada

  1. Use Windows x64 com Java 25+, Python 3 e Microsoft Edge.
  2. Extraia o ZIP verificado em uma pasta nova e gravável pelo usuário.
  3. Execute iniciar_pdv.bat (underscore); o launcher inicia o backend e abre o Edge em modo aplicativo.
  4. No primeiro acesso, admin/admin exige troca de senha.

O banco é criado em ./data/caracore-pdv.db. Esta versão não abre nem altera %APPDATA%\caracore\data\banco.db. Não copie uma pasta data de outra instalação.
