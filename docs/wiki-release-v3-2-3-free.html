Versão atual do CaraCore PDV (3.2.3-free, 06/09/2026). Windows, Linux e macOS · Java 25+. Planos Free e Premium são do produto, não desta release. A próxima versão está em 4.0.0-rc2.

O que foi corrigido

  • Porta 8080: o pacote escuta em http://localhost:8080. Health em /q/health.
  • Tela de operador: /login e /j_security_check funcionam. Primeiro acesso admin / admin com troca obrigatória de senha (8 a 15 caracteres, diferente de admin).
  • Versão no boot e na UI: 3.2.3-free, não mais 3.0.2.
  • Launcher: iniciar-pdv.bat e iniciar-pdv.sh recusam Java ausente ou abaixo de 25, com mensagem clara (o Java 21 no PATH não inicia este pacote).

Instalação com sucesso

  1. Instale Java 25+ (Temurin 25). Feche e abra o terminal; java -version tem que mostrar 25. Java 21 no PATH faz o launcher parar.
  2. Baixe o ZIP da sua plataforma na página de download.
  3. Extraia em uma pasta nova (exemplo: C:\CaraCore\pdv-free). Não extraia na pasta da prévia 4.0.0-rc2.
  4. Windows: execute iniciar-pdv.bat (hífen — a prévia v4 usa iniciar_pdv.bat). Linux/macOS: chmod +x iniciar-pdv.sh e ./iniciar-pdv.sh.
  5. Aguarde cerca de 10 segundos. Abra o navegador em http://localhost:8080.
  6. Clique em Entrar no sistema ou abra http://localhost:8080/login.
  7. Entre com admin / admin e defina a senha nova.

O launcher só sobe o backend local. Não espera uma janela JavaFX: o acesso do operador desta edição Free é no navegador. O log de arranque deve dizer 3.2.3-free.

Dados: SQLite local em %APPDATA%\caracore\ (Windows) ou ~/.caracore/ (Linux/macOS).
