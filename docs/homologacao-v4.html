Ambiente: Windows x64, Edge em modo aplicativo 1280×800, Java 25+, Python 3, ZIP extraído em pasta nova, banco em ./data/caracore-pdv.db. Um ciclo com rede e um ciclo com a rede desligada. Conferir o SHA-256 do ZIP com a loja, o GitHub e a wiki antes de extrair.

Bootstrap, Font Awesome, ApexCharts e Quagga são servidos pelo próprio aplicativo. Não há fallback de CDN. Se o arquivo local faltar, a tela quebra; o aplicativo não busca o arquivo na internet.
