O que esta versão entrega no Free

  • Shell PDV: coluna esquerda fixa (~264px) com Início, Produtos e Caixa / venda; usuário/Sair na sidebar; header só com marca + versão.
  • Mapa Premium: itens com badge Restrito empilhados (um por linha). Em 1280px+ não há fila horizontal.
  • Caixa registradora: busca/código dominante com foco ao abrir; Enter adiciona 1 un.; carrinho legível; total grande e sempre visível.
  • Pagamento: Dinheiro / Débito / Crédito / Outros (registro manual honesto). Atalhos na UI: F2 busca, F4 pagar, Esc cancelar.
  • Aviso PIX: um aviso compacto — sem empilhar banners.
  • Login: depois da troca de senha, /login não vende admin/admin como válido.
  • Versão no boot: 3.2.6-free (Maven 3.2.6 · display 3.2.6-free).

Aceite QA (Windows)

  • Sidebar em coluna em /inicio, /produtos, /caixa
  • Restrito empilhado (não em linha)
  • Caixa usável só com teclado: buscar → Enter → pagar
  • Total visualmente dominante
  • Sem PIX/NF-e falso; contadores e Restrito intactos

Instalação com sucesso

  1. Instale Java 25+ (Temurin 25). java -version tem que mostrar 25.
  2. Baixe o ZIP da sua plataforma na página de download.
  3. Extraia em pasta nova. Windows: iniciar-pdv.bat. Linux/macOS: ./iniciar-pdv.sh.
  4. Abra http://localhost:8080/login, troque a senha no primeiro acesso e use a senha nova daí em diante.
  5. No caixa: foque a busca (F2), digite o código, Enter, F4 para pagar.

O log de arranque deve dizer 3.2.6-free. Banco em %APPDATA%\caracore\ (Windows) ou ~/.caracore/ (Linux/macOS).
