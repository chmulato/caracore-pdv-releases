PWA da loja

Este atalho abre a vitrine pública: download, instaladores e roadmap. O caixa do PDV não roda neste site.

O CaraCore-PDV é um sistema desktop local com SQLite no computador da loja. A PWA da loja é só a vitrine. Para vender, baixe o pacote v3.2.2-free (Windows, Linux ou macOS) e execute o launcher do ZIP.

Como instalar a loja no aparelho

  1. Abra esta página no Chrome, Edge ou Safari.
  2. Use Instalar aplicativo / Adicionar à tela inicial.
  3. O ícone abre pdv.caracore.com.br em modo aplicativo.

Sem internet, o atalho ainda mostra as páginas da loja já visitadas. Os ZIPs do GitHub exigem rede no momento do download.

O que esta PWA não é

  • Não é o caixa, o carrinho nem o banco da loja.
  • Não substitui o pacote Windows, Linux ou macOS da tag v3.2.2-free.
  • Não é a linha Rust (pdv-rust.caracore.com.br).

PWA do caixa (v4)

A oficina prepara o CaraCore-PDV v4 com interface web/PWA no computador da loja, aberta pelo launcher após o backend local. Lançamento previsto: 08/11/2026, depois da homologação. Até lá, o download público permanece a degustação v3.2.2-free.
