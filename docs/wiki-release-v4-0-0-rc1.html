CaraCore-PDV v4.0.0-rc1

Candidato da linha v4: Quarkus + Qute + SQLite local + launcher. Publicado em 05/09/2026 como pré-release.

Não é o canal maduro. A oferta pública para teste real continua a v3.2.2-free. O GA do v4 permanece previsto para 08/11/2026 e depende do corte T032 (Edge real, suíte completa, instalador assinado).

O que este candidato entrega

  • Interface web Qute em modo aplicativo (Edge no Windows; Chrome/Chromium/Edge no Linux e macOS).
  • Paridade de negócio das Fases 0–7 na oficina (venda, caixa, cadastros, fiscal, backup, offline, personas).
  • Um ZIP portátil para Windows, Linux e macOS. Requisito: Java 25+ e Python 3.
  • Primeiro acesso: admin / admin, com troca de senha obrigatória.

Como instalar

  1. Baixe caracore-pdv-4.0.0-rc1-qute-portable.zip.
  2. Extraia para uma pasta local.
  3. Windows: execute iniciar_pdv.bat. Linux/macOS: chmod +x iniciar_pdv.sh && ./iniciar_pdv.sh.
  4. O launcher sobe http://127.0.0.1:8080 e abre o navegador em modo aplicativo.
