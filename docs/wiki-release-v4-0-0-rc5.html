Download e verificação

Antes de extrair, compare o SHA-256 abaixo com o resultado local. O hash ajuda a detectar alteração do arquivo, mas não autentica a identidade do publicador.

Arquivo: CaraCore-PDV-4.0.0-rc5-qute-portable-windows-x64.zip
SHA-256: d45d12d9fbf6e3923f69ddbbf6173ef2128be0341e30e75f038b7dc1f3ab6f81

No PowerShell: Get-FileHash .\CaraCore-PDV-4.0.0-rc5-qute-portable-windows-x64.zip -Algorithm SHA256

Este ZIP não tem assinatura Authenticode. O Windows pode exibir alertas de editor desconhecido ou reputação. Não desative SmartScreen, Defender ou antivírus; interrompa se o hash divergir.

Instalação isolada

  1. Use Windows x64 com Java 25+, Python 3 e Microsoft Edge.
  2. Extraia o ZIP verificado em uma pasta nova e gravável pelo usuário.
  3. Execute iniciar_pdv.bat (underscore); o launcher inicia o backend e abre o Edge. Se o Java padrão não for o 25, defina JAVA_HOME ou PDV_JAVA para o JDK 25 antes de executar.
  4. No primeiro acesso, admin/admin exige troca de senha. Depois da troca, o console não repete essas credenciais.

O banco é criado em ./data/caracore-pdv.db. Um banco legado em %APPDATA%\caracore\data\banco.db, se existir, não é aberto nem alterado.
