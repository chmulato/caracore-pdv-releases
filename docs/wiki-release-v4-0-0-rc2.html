PREVIEW — not store download. Não misture pasta nem data. Canais independentes. Para o balcão hoje, Baixar Free (3.2.4). Esta prévia substitui a 4.0.0-rc1. Publicação plena prevista para 08/11/2026.

O que mudou em relação à RC1

  • Login inicial admin / admin volta a funcionar no banco isolado deste pacote.
  • O launcher usa só ./data/caracore-pdv.db. Não reabre o banco legado em %APPDATA%\caracore\data\banco.db.
  • Logout web encerra a sessão e volta à tela de login.

Instalação limpa (obrigatória neste RC)

  1. Baixe caracore-pdv-4.0.0-rc2-qute-portable.zip (SHA256 5e5d55b6d376c7f1d6ce91a9fb9a73f6d606289af27b508adf2d9eb2cdcd955d).
  2. Java 25+ e Python 3. Depois do Temurin 25, feche e abra o terminal; java -version tem que mostrar 25.
  3. Extraia em uma pasta nova (exemplo: C:\CaraCore\pdv-v4-rc2). Não extraia por cima da pasta do RC1 nem da 3.2.4-free.
  4. Não copie a pasta data de outro teste.
  5. Windows: execute iniciar_pdv.bat (underscore — o Free usa iniciar-pdv.bat, com hífen). Linux/macOS: chmod +x iniciar_pdv.sh && ./iniciar_pdv.sh.
  6. O launcher sobe o backend e abre o Edge em modo aplicativo (não é o Free no navegador).
  7. Entre com admin / admin e troque a senha (8 a 15 caracteres).

O banco deste RC fica só ao lado do launcher, em ./data/caracore-pdv.db. O arquivo legado %APPDATA%\caracore\data\banco.db pode continuar no disco — este RC2 não o abre e não precisa ser apagado para “limpar” a v4.

Em instalação limpa, o log pode dizer que a carga inicial foi ignorada: o Flyway já criou o banco em ./data. Isso é normal. Só extraia de novo se o caminho for fora de ./data ou se o login falhar.
