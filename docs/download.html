Instalação com sucesso — Free 3.2.5

Este é o download do balcão. Extraia em pasta nova. A prévia 4.0.0-rc2 fica em outra pasta, com outro launcher.

Java 25 no PATH

Depois de instalar o Temurin 25, feche e abra o terminal. java -version tem que mostrar 25. Muita máquina ainda tem Java 21 na frente — nesse caso o launcher para e explica o que falta. Esse comportamento é aceito.

  1. 1Confira o Java 25+ num terminal novo com java -version.
  2. 2Baixe o ZIP da sua plataforma nesta página (nome + SHA256 acima).
  3. 3Extraia em uma pasta nova e permanente, por exemplo C:\CaraCore\pdv-free. Não extraia na Área de trabalho nem na pasta da prévia.
  4. 4Windows: execute iniciar-pdv.bat (hífen). Linux/macOS: chmod +x iniciar-pdv.sh e depois ./iniciar-pdv.sh.
  5. 5O launcher só sobe o backend. Abra o navegador em http://localhost:8080 — não espera janela JavaFX.
  6. 6Clique em Entrar no sistema ou abra http://localhost:8080/login. Usuário admin, senha admin. A troca de senha é obrigatória (8 a 15 caracteres, diferente de admin).
  7. 7Cadastre um produto e registre a primeira venda no caixa pela interface do navegador. Pagamentos no Free: dinheiro, débito, crédito e outros — “outros” não é o PIX integrado da loja.

Quem entra neste Free

O ZIP cria um operador: admin / admin. A troca de senha é obrigatória. O plano Free limita a 1 operador de caixa — não há logins extras de demonstração nesta edição.

Não use senhas do piloto Rust (admin123, Operador@1234…). É outro programa, outra pasta (%APPDATA%\caracore\ aqui; o Rust usa %APPDATA%\caracore-pdv\).

O boot deve identificar 3.2.5-free. Health: http://localhost:8080/q/health. O banco fica em %APPDATA%\caracore\ (Windows) ou ~/.caracore/ (Linux/macOS). Notas: 3.2.5-free.

Prévia — não é o download da loja

4.0.0-rc2

Canais independentes: não misture pasta nem data. Não apague o AppData da v3 “pra limpar” a v4 — a RC2 não abre %APPDATA%\caracore\data\banco.db. O launcher abre o Edge em modo aplicativo.

  1. 1Baixe caracore-pdv-4.0.0-rc2-qute-portable.zip na página da RC2 (SHA256 5e5d55b6d376c7f1d6ce91a9fb9a73f6d606289af27b508adf2d9eb2cdcd955d).
  2. 2Extraia em uma pasta nova (exemplo: C:\CaraCore\pdv-v4-rc2).
  3. 3Não copie a pasta data de outro teste. O banco desta prévia fica só em ./data/caracore-pdv.db.
  4. 4Windows: iniciar_pdv.bat (underscore). Linux/macOS: ./iniciar_pdv.sh. Precisa de Java 25+ e Python 3.
  5. 5Login: admin / admin, depois troque a senha. O launcher confirma o caminho do banco no arranque.

O arquivo legado %APPDATA%\caracore\data\banco.db pode continuar no disco. Em instalação limpa, o log pode dizer que a carga inicial foi ignorada — o Flyway já criou o banco em ./data; isso é normal.

ZIP antigo / problemas

Se a porta for 8765 ou /login der 404, você ainda está no ZIP 3.2.2-free. Baixe de novo a 3.2.5-free nesta página e extraia em pasta nova. Notas históricas: 3.2.4-free · 3.2.3-free · 3.2.2-free.
