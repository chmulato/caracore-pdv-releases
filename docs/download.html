Instalação 3.2.7-free (estável)

  1. Tenha o JDK 25 (java -version mostra 25).
  2. Extraia o ZIP em uma pasta nova (exemplo: C:\CaraCore\pdv-free).
  3. Windows: iniciar-pdv.bat (hífen). Linux/macOS: ./iniciar-pdv.sh.
  4. Abra http://localhost:8080/login no navegador. Primeiro acesso: admin / admin.
  5. Troque a senha (obrigatório) e registre a primeira venda.

Os dados ficam em %APPDATA%\caracore\ (Windows) ou ~/.caracore/ (Linux e macOS). Os logs ficam em %APPDATA%\caracore\logs.

Quem entra: um operador — admin / admin, com troca de senha obrigatória. Sem logins extras neste ZIP.

Instalação 4.0.0-rc6 (pré-release)

Windows x64. Não é a versão estável. Sem NF-e, NFC-e nem PIX integrado.

  • JDK 25 (Java 25).
  • Python 3.10 ou mais novo. Na instalação, marque “Add python.exe to PATH”.
  • Microsoft Edge.

Se o seu computador tem outro Java como padrão (ex.: 21), defina JAVA_HOME ou PDV_JAVA apontando para o Java 25.

  1. Extraia o ZIP em uma pasta nova, separada da 3.2.7-free.
  2. Execute iniciar_pdv.bat (sublinhado). O launcher sobe o caixa e abre o Edge.
  3. Primeiro acesso: admin / admin, com troca de senha obrigatória. Depois da troca, essas credenciais deixam de valer.

Banco e logs ficam na pasta extraída: .\data\caracore-pdv.db e .\data\logs. Essa instalação não usa %APPDATA%\caracore\.

A 4.0.0-rc5 fica no histórico.

Limites do Free

  • Até 100 vendas/mês · 100 produtos · 1 operador · 4 vendedores · 1 loja.
  • Offline (SQLite) · balcão no navegador. Pagamentos: dinheiro, débito, crédito e outros — “outros” não é PIX integrado.
  • Recibo digital por link e PDF, sem valor fiscal.
  • Sem PIX integrado (QR/gateway) e sem NF-e/NFC-e.
