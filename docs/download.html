Instalação

  1. Tenha Java 25+ no PATH (java -version mostra 25).
  2. Extraia o ZIP em uma pasta nova (exemplo: C:\CaraCore\pdv-free).
  3. Windows: iniciar-pdv.bat (hífen). Linux/macOS: ./iniciar-pdv.sh.
  4. Abra http://localhost:8080/login no navegador. Primeiro acesso: admin / admin.
  5. Troque a senha (obrigatório) e registre a primeira venda.

Quem entra: um operador — admin / admin, com troca de senha obrigatória. Sem logins extras neste ZIP.

Limites do Free

  • Até 100 vendas/mês · 100 produtos · 1 operador · 4 vendedores · 1 loja.
  • Offline (SQLite) · balcão no navegador. Pagamentos: dinheiro, débito, crédito e outros — “outros” não é PIX integrado.
  • Sem PIX integrado (QR/gateway) e sem NF-e/NFC-e.

Problemas comuns / Avançado

ZIP antigo ou porta 8765 (ou /login dá 404) → baixe de novo a 3.2.6 e extraia em pasta nova. Histórico: Versões.

O Free abre no navegador, não em janela JavaFX. Health: http://localhost:8080/q/health. Banco: %APPDATA%\caracore\ (Windows) ou ~/.caracore/.

Depois do Temurin 25, feche e abra o terminal. Se java -version ainda mostrar 21, o launcher para e explica o que falta.

Não use senhas do piloto Rust — outro programa. Perfis Rust.
