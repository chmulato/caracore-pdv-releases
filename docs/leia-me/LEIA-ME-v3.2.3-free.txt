INSTALAÇÃO
----------
1. Java 25+ no PATH. Depois do Temurin 25, feche e abra o terminal.
   java -version tem que mostrar 25. Java 21 no PATH faz o launcher parar.
2. Extraia em uma pasta nova e permanente (exemplo: C:\CaraCore\pdv-free).
   Não extraia na pasta da prévia v4.
3. Windows: iniciar-pdv.bat (hífen)
   Linux/macOS: chmod +x iniciar-pdv.sh && ./iniciar-pdv.sh
4. O launcher só sobe o backend. Abra o NAVEGADOR em
   http://localhost:8080/login
   Não espera janela JavaFX.
5. Primeiro acesso: admin / admin (troque a senha, 8 a 15 caracteres).
