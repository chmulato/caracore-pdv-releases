Versões do CaraCore PDV

A mesma operação de caixa. Números de versão, não lojas diferentes.

Versão 3.2.12-free publicada. Validações de homologação em andamento, ver notas da versão. A prévia 4.0.0-rc6 está disponível para avaliação no Windows. Instale cada versão em uma pasta separada.

As duas versões seguem o plano Free, com limite de 100 vendas por mês. A 3.2.12-free abre no navegador no Windows, Linux e macOS; sua homologação está em andamento. A 4.0.0-rc6 é uma prévia para avaliação no Windows e abre no Edge. A versão final da v4 depende de aprovação formal, sem data automática de lançamento.

Pré-release Free 4.0.0-rc6 — somente para avaliação

A 4.0.0-rc6 usa o plano Free, com até 100 vendas por mês. É uma prévia para avaliação, não a versão final. Extraia em pasta nova e execute iniciar_pdv.bat (sublinhado). Os dados e registros de execução ficam em .\data. Requer Windows 10/11 x64 e Microsoft Edge. Não precisa instalar Java: ele vem dentro do ZIP.

Distribuição somente em ZIP portátil Windows x64 sem assinatura digital; sem instalador MSI. SHA256: 0c00b24b33b3c365fd1f24ec173bfa4e35bedf1946b2df4151035250780d5325.
